# Hermes: página e política de privacidade

Site estático publicado no GitHub Pages: **https://fabriciodimoraes231-rgb.github.io/hermes-app/**

O Hermes é um assistente pessoal de uso privado que roda num Raspberry Pi doméstico. Ele acessa a conta Google do próprio dono (Agenda, Gmail, Drive e Planilhas) para resumir e-mails, lembrar compromissos, manter uma planilha financeira e guardar backups.

O Google exige uma página inicial e uma política de privacidade públicas para liberar o login OAuth de um app. Este repositório existe só para isso.

| Página | Conteúdo |
|---|---|
| [`index.html`](https://fabriciodimoraes231-rgb.github.io/hermes-app/) | O que é o Hermes e quem pode usá-lo |
| [`privacidade.html`](https://fabriciodimoraes231-rgb.github.io/hermes-app/privacidade.html) | Dados acessados, uso e armazenamento, compartilhamento e como revogar o acesso |

O Hermes não é um serviço público e não aceita outros usuários. O código do assistente não fica aqui.
