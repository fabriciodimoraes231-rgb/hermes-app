Política de privacidade do Hermes

Última atualização: 22 de outubro de 2026.

O Hermes é um assistente pessoal usado somente pelo seu dono, na própria conta Google dele.

Dados acessados

Com a autorização do dono, o Hermes pode acessar Gmail, Google Agenda, Google Drive e Planilhas Google da conta dele.

Uso e armazenamento

Os dados são usados apenas para as tarefas pedidas pelo próprio dono (resumos, lembretes, controle financeiro e backups). Os tokens de acesso ficam guardados somente no dispositivo do dono.

Compartilhamento

Nenhum dado do Google é vendido, compartilhado com terceiros ou usado para publicidade. O uso de dados obtidos pelas APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
